## 🛠 KURULUM (STEP BY STEP)

`Adım 1: Veritabanı` **SQL/database.sql**
*   `SQL/new.sql` dosyasını phpMyAdmin veya MySQL panelinden içeri aktarın. Bu, tüm tablo yapısını ve v4 güncellemelerini kuracaktır.

`Adım 2: Yapılandırma` **app/config.php**
*   `app/config.php` dosyasını açın ve kendi veritabanı bilgilerinizi girin:
    ```php
    'db_name' => 'veritabani_adin',
    'db_user' => 'kullanici_adin',
    'db_pass' => 'sifren'
    ```

`Adım 3: Yükleme` **htdocs**
*   Tüm dosyaları hostinginizin ana dizinine (genelde `public_html` veya `htdocs`) yükleyin.
